🧩 2. RAG Chunking Strategies Decision Matrix

Strategy Typical Size Boundary Logic Best Used For Critical Trade-off
Fixed-Size 256 - 512 tokens Arbitrary token/char count with 10% overlap High-volume raw text, uniform baseline Splits sentences and code mid-syntax.
Recursive Character 512 - 1000 tokens Hierarchical delimiters: `\n\n`, `\n`, ` `, `""` General articles, prose, markdown notes Irregular chunk sizes vary variance in vector scores.
Document AST / Header Variable (by section) Markdown `#` headers, HTML tags, code functions Engineering docs, Confluence, API specs Requires clean structured source documents.
Semantic Shift Dynamic Embedding cosine drop between adjacent sentences Transcripts, conversational logs, podcasts High computational overhead during offline ingestion.
Parent-Child / Hierarchical Small (128) child, Large (1024) parent Search small chunk; return parent context to LLM Dense factual question answering, manuals Increases context token load during prompt synthesis.

Python: Reciprocal Rank Fusion (RRF) Dense + BM25 Hybrid 
def reciprocal_rank_fusion(dense_ranks, bm25_ranks, k=60):
    """Fuses dense vector and sparse keyword rankings."""
    rrf_scores = {}
    for rank, doc_id in enumerate(dense_ranks):
        rrf_scores[doc_id] = rrf_scores.get(doc_id, 0.0) + (1.0 / (k + rank + 1))
    for rank, doc_id in enumerate(bm25_ranks):
        rrf_scores[doc_id] = rrf_scores.get(doc_id, 0.0) + (1.0 / (k + rank + 1))
    
    # Sort descending by fused score
    return sorted(rrf_scores.items(), key=lambda x: x[1], reverse=True)
